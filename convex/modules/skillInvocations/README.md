# Skill Invocations Module

Convex-backed skill invocation telemetry for Codex `PostToolUse` hook events.

## Files

- `schema.ts`: module-owned table definition.
- `validators.ts`: shared Convex validators.
- `contracts.ts`: pure dashboard summarizer.
- `httpContracts.ts`: HTTP payload parser.
- `events.ts`: internal ingestion mutation.
- `queries.ts`: dashboard query.
