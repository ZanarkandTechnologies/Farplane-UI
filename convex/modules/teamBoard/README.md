# Team Board Module

Convex-backed office task board, task events, CEO review lanes, and project timeline queries.

## Files

- `schema.ts`: `teamBoardTasks` and `teamBoardEvents` table definitions.
- `contracts.ts`: board/task/activity coercion helpers.
- `httpContracts.ts`: HTTP payload parsing for board ingress.
- `board.ts`: public board mutations and queries.
