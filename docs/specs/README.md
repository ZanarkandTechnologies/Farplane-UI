# Legacy Specs Migration

First-class feature specs moved to `docs/features/FEAT-*.md` during the
Farplane framework `1.6.4` documentation-OS migration.

Use:

- `docs/features/README.md` for canonical feature/capability specs.
- `docs/systems/README.md` for system/product-layer groupings and boundaries.

This folder remains only for legacy or historical material whose owner is not a
current feature spec.

  direction study referenced by feature docs. It is not a feature owner doc.
