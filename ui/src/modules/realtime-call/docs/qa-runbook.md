# QA Runbook

1. Open a call with one configured employee and confirm the setup portrait and Local override badge.
2. Start the session and confirm connecting becomes connected with the microphone published.
3. Mute and resume the microphone, then toggle camera and screen share; verify browser permission
   failures appear inline.
4. Confirm subscribed agent speech drives the mouth/wave treatment and transcript text appears.
5. End the call and verify the room disconnects before the dialog closes.
6. Select employees from two projects and confirm no profile or session request starts.
7. Select an agent without a local profile and confirm the setup action names the missing profile.
8. Call Finance, People Operations, and Office Manager individually and together; confirm the
   setup header says `Executive Office` and the three tracked office profiles load.
9. Mix an office specialist with a project worker and confirm no profile or session request starts.
